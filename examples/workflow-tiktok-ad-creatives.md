# Multi-Agent Workflow: TikTok Ad Creatives

> Brainstorm, script, design, and launch TikTok ad creatives using a 9-agent team — from trend research to ready-to-run ads.

## The Scenario

You need a batch of high-performing TikTok ad creatives: short-form video scripts, visual storyboards, ad copy, and thumbnail prompts — all aligned with current trends, your brand, and your paid strategy. The workflow takes you from trend research to campaign-ready assets.

## Agent Team

### Core Trio

| Agent | Role in this workflow |
|-------|---------------------|
| TikTok Strategist 🎵 | Trend research, algorithm insights, viral hooks for first 3 seconds |
| Ad Creative Strategist ✍️ | Ad copy, creative structure, RSA optimization, CTAs |
| Image Prompt Engineer 📸 | Generate prompts for visuals, thumbnails, and storyboard frames |

### Creative Enhancement

| Agent | Role in this workflow |
|-------|---------------------|
| Visual Storyteller 🎬 | Visual narrative arc: problem → solution in 15-30 seconds |
| Whimsy Injector ✨ | Add humor, unexpected twists, "scroll-stopping" moments |
| Content Creator 📝 | Multi-format scripts, series concepts, content variations |
| Brand Guardian 🎨 | Keep everything on-brand — tone, visual identity, positioning |

### Paid Promotion

| Agent | Role in this workflow |
|-------|---------------------|
| Paid Social Strategist | Targeting, audiences, budgets for TikTok Ads |
| Carousel Growth Engine | Carousel ad formats (growing TikTok format) |

## The Workflow

### Phase 1: Trend Research & Strategy

**Step 1 — Activate TikTok Strategist**

```
Activate TikTok Strategist.

Research current TikTok trends for [YOUR NICHE/PRODUCT].

Deliver:
1. Top 3 trending formats right now (with examples)
2. Top 5 sounds/audio clips gaining traction
3. Best-performing hook patterns for the first 3 seconds
4. Optimal video lengths for ads in this niche
5. Hashtag strategy (mix of trending + niche + branded)
6. Posting time recommendations based on target audience

Be specific — link to real trend patterns, not generic advice.
```

**Step 2 — Activate Paid Social Strategist (in parallel)**

```
Activate Paid Social Strategist.

We're planning TikTok ad campaigns for [YOUR PRODUCT/BRAND].

Define:
1. Target audience segments (3-4 audiences with demographics + interests)
2. Campaign structure recommendation (awareness / consideration / conversion)
3. Budget allocation across ad groups
4. Bidding strategy for each objective
5. Placement recommendations (TikTok feed, Pangle, etc.)
6. KPIs and benchmarks for each campaign type

Budget: [YOUR BUDGET]. Goal: [YOUR PRIMARY GOAL].
```

### Phase 2: Ideation & Scripting (parallel)

**Step 3a — Activate Content Creator**

```
Activate Content Creator.

Based on TikTok Strategist's trend research:
[paste TikTok Strategist output]

Generate 10 creative concepts for [YOUR PRODUCT]:
1. For each concept: title, format type, hook, core message, CTA
2. Mix of formats: 3 educational, 3 storytelling, 2 UGC-style, 2 trending format adaptations
3. Write full scripts for the top 5 concepts (with timestamps)
4. Include on-screen text overlays for each script
5. Suggest series potential — which concepts could become recurring content

Target duration: 15-30 seconds per ad.
```

**Step 3b — Activate Ad Creative Strategist (in parallel)**

```
Activate Ad Creative Strategist.

We're creating TikTok ads for [YOUR PRODUCT].

For each of these 5 scripts: [paste Content Creator's top 5 scripts]

Deliver:
1. Ad copy variants (3 versions per script): headline + body + CTA
2. CTA button recommendations for each concept
3. A/B testing plan: what to test first (hook, CTA, format)
4. Creative fatigue prevention: rotation schedule
5. Platform-specific copy optimization (TikTok character limits, text-on-screen best practices)
6. Spark Ads adaptation: how to repurpose each script for organic-to-paid
```

### Phase 3: Visual Design & Storyboarding

**Step 4 — Activate Visual Storyteller**

```
Activate Visual Storyteller.

Create detailed storyboards for these 5 ad scripts:
[paste top 5 scripts from Content Creator]

For each storyboard:
1. Frame-by-frame breakdown (6-10 frames per 15-30s video)
2. Camera angles and shot types for each frame
3. Transition types between frames
4. On-screen text placement and timing
5. Color mood for each scene
6. Visual hierarchy: what the eye should focus on per frame

Optimize for vertical 9:16 format. Think mobile-first.
```

**Step 5 — Activate Whimsy Injector**

```
Activate Whimsy Injector.

Review these 5 ad storyboards and scripts:
[paste Visual Storyteller storyboards + Content Creator scripts]

For each creative:
1. Identify the "scroll-stop moment" — is it strong enough? If not, suggest a better one
2. Add an unexpected twist or humor beat (one per script)
3. Suggest a pattern interrupt for frame 2-3 to boost retention
4. Rate each script's "shareability factor" (1-10) and explain why
5. Propose one "wild card" version of each script — same message, completely different execution

Goal: make these ads feel native to TikTok, not like ads.
```

### Phase 4: Brand Alignment

**Step 6 — Activate Brand Guardian**

```
Activate Brand Guardian.

Review all creative assets for brand alignment:

Scripts: [paste final scripts]
Storyboards: [paste storyboards]
Ad copy: [paste Ad Creative Strategist output]

Brand guidelines:
- Brand voice: [YOUR BRAND VOICE]
- Visual identity: [YOUR BRAND COLORS/STYLE]
- Do's and don'ts: [YOUR BRAND RULES]

Evaluate:
1. Tone consistency: does each script match our brand voice?
2. Visual alignment: do storyboards respect our visual identity?
3. Messaging accuracy: are product claims truthful and compliant?
4. Red flags: anything that could be off-brand, controversial, or risky?
5. Specific edits: exact changes needed (not vague feedback)

Approve or request revisions for each creative.
```

### Phase 5: Visual Asset Generation

**Step 7 — Activate Image Prompt Engineer**

```
Activate Image Prompt Engineer.

Generate image prompts for these TikTok ad assets:
[paste approved storyboards from Visual Storyteller]

For each of the 5 creatives, deliver:
1. Thumbnail/cover image prompt (1:1 and 9:16 versions)
2. Key frame prompts for storyboard visualization (3-5 per creative)
3. Product shot prompts (lifestyle context, not white background)
4. Before/after comparison prompts (if applicable)
5. Text overlay background prompts (designed for text readability)

All prompts must specify:
- Aspect ratio (9:16 for TikTok)
- Style (photorealistic / illustrated / mixed media)
- Lighting and color mood
- Composition and focal point
```

### Phase 6: Carousel & Format Expansion

**Step 8 — Activate Carousel Growth Engine**

```
Activate Carousel Growth Engine.

Adapt these 5 ad concepts for TikTok carousel format:
[paste final approved concepts]

For each carousel:
1. Slide count (optimal 4-7 slides)
2. Content per slide: headline + visual description + supporting text
3. Narrative flow: how slides build on each other
4. First slide hook (must stop the scroll)
5. Last slide CTA (clear action + urgency)
6. Swipe motivation: why would someone swipe to the next slide?

Format: vertical 9:16 per slide. Design for thumb-stopping impact.
```

## How Agents Collaborate

```
TikTok Strategist     → "Trending format X, sound Y, hook pattern Z"
        ↓
Content Creator        → "10 script ideas, here are the top 5 fully written"
        ↓
Ad Creative Strategist → "Ad copy, CTAs, A/B test plan for each"
        ↓
Visual Storyteller     → "Frame-by-frame storyboards for each script"
        ↓
Whimsy Injector        → "Added twist in frame 3, boosted shareability"
        ↓
Brand Guardian         → "Adjusted tone in scripts 2 and 4, approved the rest"
        ↓
Image Prompt Engineer  → "Prompts for thumbnails, key frames, product shots"
        ↓
Carousel Growth Engine → "Carousel versions of top 3 concepts"
        ↓
Paid Social Strategist → "Campaign structure, targeting, budgets — ready to launch"
```

## Tips for Best Results

1. **Start with specifics**: Replace all `[YOUR ...]` placeholders with real product/brand details
2. **Run Phase 1 in parallel**: TikTok Strategist and Paid Social Strategist can work simultaneously
3. **Iterate in Phase 3-4**: Visual Storyteller → Whimsy Injector → Brand Guardian is a review loop — run it twice if needed
4. **Batch your creatives**: Run 5 concepts through the pipeline, then pick the best 2-3 for production
5. **Use Brand Guardian as a gate**: Nothing goes to Phase 5 without Brand Guardian approval
6. **Test the Ad Creative Strategist's A/B plan**: Let data decide which hooks and CTAs win

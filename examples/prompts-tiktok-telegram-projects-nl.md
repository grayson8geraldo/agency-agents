## Phase 2: Ideation & Scripting

### Step 3a — Content Creator 📝

```
Activate Content Creator.

Create TikTok ad scripts for 3 Telegram bot projects targeting Netherlands (M+F, 18-45).
Funnel: TikTok creative → pre-landing → Telegram bot.

PROJECT 1: SNELL COIN 🪙
- Telegram clicker game: tap coin → earn currency, energy system, daily tasks
- Angles: simplicity ("just tap"), FOMO ("everyone's playing"), crypto-lite, gamer nostalgia, side-earning
- Tone: energetic, playful, game-vibes

PROJECT 2: EARNTUBE 📺
- Telegram bot: watch 5 short videos/day → earn points
- Angles: "you already scroll for free", 5-minute routine, comparison (free scrolling vs paid watching), morning routine
- Tone: relaxed, "too good to be true but real"

PROJECT 3: REAL OR FAKE 🔍 (coming soon, for future use)
- Telegram quiz: guess if image is real or AI-generated
- Angles: challenge ("90% get it wrong"), AI hype, ego-bait, quiz-format in the creative itself
- Tone: intriguing, challenging

For EACH project deliver:
1. 10 creative concepts: title, format, hook (first 3 sec), core message, CTA
2. Mix: 3 educational, 3 storytelling, 2 UGC-style, 2 trending format adaptations
3. Full scripts for TOP 5 concepts with timestamps (15-30 sec each)
4. On-screen text overlays for each script
5. Series potential: which concepts can become recurring content

Script structure:
- Sec 1-3: HOOK (stop the scroll)
- Sec 4-12: PROBLEM → SOLUTION (show the product)
- Sec 13-20: PROOF (bot screen, numbers, reaction)
- Sec 21-30: CTA → "Link in bio" / "Check the link"

CTA must drive to pre-landing page, NOT directly to Telegram.
Language: English (Dutch population understands English well). Optionally note where Dutch versions would hit harder.

IMPORTANT: Do NOT promise real money or guaranteed income — TikTok will ban the ad.
Avoid: "make money", "guaranteed earnings", "get rich". Use: "earn points", "collect coins", "get rewarded".
```

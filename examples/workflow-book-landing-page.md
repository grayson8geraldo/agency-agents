# Multi-Agent Workflow: Landing Page для авторской книги о каркасном строительстве

> Создание конверсионного лендинга для книги «Каркас над пропастью: строю дом на болоте» (Юрий Подымахин) с помощью 10 агентов.

## О проекте

Книга Юрия Подымахина — практическое руководство по строительству каркасного дома на болотистой (торфяной) почве. Автор — не профессиональный строитель, а энтузиаст с удостоверением плотника 2-го разряда, который в одиночку построил дом на бывших торфоразработках. Книга содержит ~1200 фотографий и рисунков, охватывает фундаменты для болотистых почв, дренаж, каркасную технологию «платформа», декоративно-прикладное творчество.

**Целевая аудитория**: самостройщики, дачники, владельцы участков на сложных грунтах, люди планирующие строить дом своими руками.

**Цель лендинга**: продажа книги через CTA-кнопку (маркетплейсы, сайт автора podymakhin.ru).

## Workflow

### Фаза 1: Брендинг и контент (параллельно)

**Шаг 1a — Activate Brand Guardian**

```
Activate Brand Guardian.

Разработай брендинг для лендинга авторской книги «Каркас над пропастью: строю дом на болоте».

Контекст: Книга о строительстве каркасного дома на болотистой почве.
Автор — Юрий Подымахин, практик-самостройщик, не профессиональный строитель.
Тон книги: честный, практичный, вдохновляющий. Девиз: «Делай хорошо — плохо само получится!»

Нужно:
1. Цветовая палитра (навеяна стройкой + природой: дерево, болото, снег)
2. Типографика (шрифтовая пара: заголовки + текст)
3. Тон коммуникации (русскоязычная аудитория, самостройщики 35-55 лет)
4. Визуальные правила: стиль фотографий, иконок, кнопок
5. Ограничения: что НЕ использовать (кричащие цвета, стоковые фото строителей в касках)

Цель: лендинг должен выглядеть как продукт с душой, не как шаблон.
```

**Шаг 1b — Activate Content Creator (параллельно)**

```
Activate Content Creator.

Напиши продающий контент для лендинга книги «Каркас над пропастью: строю дом на болоте» (Юрий Подымахин).

О книге:
- Практическое руководство по каркасному строительству на болотистой почве
- Автор строил дом один, на бывших торфоразработках
- ~1200 фотографий и рисунков
- Темы: фундаменты на болоте, дренаж, каркасная технология, декоративное творчество
- Указаны реальные просчёты и ошибки с примерами исправления
- Видео автора на FORUMHOUSE набрало 220+ тыс. просмотров

Секции:
1. Hero: заголовок + подзаголовок + CTA
2. Проблема: «Почему стройка на болоте — это вызов» (3 боли)
3. Решение: «Что внутри книги» (5-7 буллетов с выгодами)
4. Об авторе: краткая биография + фото с подписью
5. Для кого: целевые сегменты (3-4 персоны)
6. Содержание: ключевые главы книги
7. Социальное доказательство: формат для отзывов + упоминание FORUMHOUSE
8. FAQ: 5-6 частых вопросов
9. Финальный CTA: призыв к покупке

Язык: русский. Тон: уверенный, честный, без воды. Как разговор опытного соседа по даче.
```

**Шаг 1c — Activate Visual Storyteller (параллельно)**

```
Activate Visual Storyteller.

Разработай визуальный нарратив для лендинга книги о строительстве каркасного дома на болоте.

Структура истории:
1. ПРОБЛЕМА → «У вас участок на болоте. Все говорят — не строй. Денег нет, опыта нет.»
2. ГЕРОЙ → «Один человек решил: построю сам. На болоте. С нуля.»
3. ПУТЬ → «Ошибки, находки, решения — всё задокументировано в 1200 фото»
4. РЕЗУЛЬТАТ → «Дом стоит. Книга написана. Теперь ваша очередь.»

Для каждого этапа опиши:
- Визуальный образ (что видит пользователь при скролле)
- Эмоцию, которую должен вызвать блок
- Переход между секциями (как одна секция перетекает в другую)
- Цветовое настроение (от тёмного/проблемного к светлому/результатному)

Формат: описание визуального сторибоарда для одностраничного лендинга.
```

## Ключевые паттерны

1. **Параллельный старт**: Брендинг, контент и визуальный нарратив разрабатываются одновременно
2. **Точка слияния**: UI Designer получает результаты всех трёх агентов Фазы 1
3. **Последовательная сборка**: Frontend Developer собирает всё в код → SEO оптимизирует
4. **Независимый маркетинг**: Все маркетинговые агенты работают параллельно после готовности лендинга
5. **Обратная связь**: Результаты PPC и аналитики возвращаются к Content Creator для оптимизации

# NepOfNiet — Ревью креативного пакета

## Общая оценка пакета: 8.5/10

### Сильные стороны
- Продукт идеально ложится на формат TikTok — интерактивная игра-загадка
- JTBD-карта покрывает широкий спектр мотиваций
- Встроенная виральность: реферальная механика + соревновательный формат
- Хуки сильные — используют когнитивный зуд («а я бы угадал?»)

### Зоны для усиления
- Нужна конкретика по внутренней валюте — на что тратить монеты
- Воронка TikTok → Лендинг → Telegram имеет 2 перехода (потеря на каждом)
- Не все сценарии используют ранний CTA (некоторые к середине)

## Общие рекомендации

### 1. Воронка: сократить путь
Текущая: TikTok → Лендинг → Telegram-бот (2 перехода).
**Рекомендация**: Тестировать прямую ссылку TikTok → Telegram-бот (1 переход). Лендинг использовать для ретаргетинга или SEO, но основная воронка из TikTok — напрямую в бот.

### 2. Ценность монет
Во всех сценариях упоминаются монеты, но непонятно, что с ними делать.
**Рекомендация**: Определить и коммуницировать:
- Рейтинг / лидерборд
- Обмен на что-то (контент, функции)
- Просто прогресс / статус
В креативах это можно сформулировать как: «Набери 100 монет и попади в топ-10%» или «Монеты = твой рейтинг среди игроков».

### 3. Порядок запуска
1. **Неделя 1**: A1 + E2 (два хука-стоппера для холодной аудитории)
2. **Неделя 2**: A2 + D1 (развернутые форматы для теплой аудитории)
3. **Неделя 3**: C1 + C2 (реферальные форматы — масштабирование)

### 4. Масштабирование контента
Все сценарии спроектированы как **серийные форматы** — бесконечное количество новых картинок = бесконечное количество новых роликов. Это ключевое преимущество для медленного выгорания креативов.

### 5. UGC-потенциал
Продукт идеально подходит для UGC-масштабирования:
- Каждый пользователь может записать свою реакцию на бот
- Формат «запиши скринкаст своего результата» стимулирует органический контент
- Рекомендация: запустить хештег-челлендж #NepOfNiet
